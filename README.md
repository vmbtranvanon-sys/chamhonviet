# CHẠM HỒN VIỆT

Website truyền thông hưởng ứng Ngày Văn hóa Việt Nam 24/11/2026.

## Nội dung
- Khám phá bản sắc văn hóa Việt qua trang phục, ẩm thực, di sản, lễ hội và nghệ thuật.
- Dòng thời gian các dấu mốc văn hóa.
- Gợi ý hành động dành cho người trẻ.
- Câu hỏi tương tác kiểm tra hiểu biết.

## Chạy thử
Mở `index.html` bằng trình duyệt hiện đại. Website dùng HTML, CSS và JavaScript thuần; font chữ tải từ Google Fonts khi có Internet.

## Xuất bản
Repository được cấu hình để triển khai bằng GitHub Pages thông qua GitHub Actions.
